#  Informe de Ciberseguridad: Caso Capcom

Este repositorio contiene una aplicación web interactiva desarrollada para presentar un análisis técnico, legal y normativo sobre el ataque de ransomware (Ragnar Locker) sufrido por la corporación Capcom en 2020. 

## Descripción del Proyecto
El informe evalúa las vulnerabilidades explotadas, el impacto en la Tríada CIA y el incumplimiento del deber de custodia frente a los datos exfiltrados. Todo el análisis está fundamentado y tipificado según la **Ley N° 21.459 (Delitos Informáticos)** y la **Ley N° 19.628 (Protección de la Vida Privada)** de Chile.

##  Stack Tecnológico
* **Framework:** React + Vite
* **Estilos:** Tailwind CSS (Diseño responsivo y panel de navegación)
* **Enrutamiento:** React Router Dom
* **Renderizado de Texto:** React Markdown + Remark GFM
* **Despliegue:** Vercel
